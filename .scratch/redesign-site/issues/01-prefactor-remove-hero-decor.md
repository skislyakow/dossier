# 01: Prefactor: выпилить hero-декор и двухколоночность

**What to build:** Посетитель видит полностью работающий сайт без старого декора: терминала с typewriter, печатающегося заголовка, летающих призраков и часов MSK. Hero становится одной колонкой, секции выстроены в новом порядке (Hero → Projects → Опыт → Skills → Contact). Весь контент CMS (навыки, проекты, опыт, контакты), бейджи, статистика, тема — продолжают работать. Это prefactor: «сделать изменение лёгким» перед новым дизайном.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Терминал, typing-заголовок, призраки и часы не отрисовываются; их скрипты, стили и разметка удалены
- [ ] Hero — одна колонка; секции идут в порядке Hero → Projects → Опыт → Skills → Contact
- [ ] Навыки, проекты, опыт, контакты отображаются как раньше
- [ ] Переключатель темы, back-to-top, GitHub stats toggle, бейджи, hover-подписи соцсетей работают
- [ ] Главная отвечает 200; существующие автотесты зелёные
- [ ] Визуальная проверка на dev-сервере: страница целая на десктопе и мобильном
