## (a) Missing / partial

1. **Длительность проектов не показана.** Spec US#5: *«понять траекторию и **длительность проектов**»*. Строки рендерят `date = ...(d.date || "")` (timeline.js:53-55) — одну точечную дату («Июль 2026»); только `job` получает `dateRange`. Точечная дата ≠ длительность, US закрыт частично (контракт заморожен — это требовало явной оговорки, а не молчания). → **Принято с оговоркой:** в данных нет конечных дат проектов, контракт `/api/timeline/` не менялся по решению; выдумывать диапазоны нельзя. Длительность работы показана полностью (dateRange).
2. **AC «Секция читаема на мобильных»** опирается только на ≤640px-tweaks; визуальный AC не отмечен — частично по дизайну, ждёт человека.

## (b) Not asked for (scope creep)

1. **Тест проверяет внутренности JS/CSS**, а не HTTP: `test_experience_section_chronology_and_escapes` запрещает source-подстроки вида `'+ d.title +'` и требует `function tlEsc(`. Spec Testing Decisions: *«Хороший тест проверяет внешнее поведение через HTTP, а не внутренности»*, *«JS/CSS автотестов нет»*. Это зеркалит существующий паттерн `DesignSystemTest`, но строка спеки его не авторизует. → **Принято:** repo-стандарт (seam «чтение файла с диска», задокументирован в AGENTS/спеке тестов) упраздняет оговорку спеки; подавлено правилом «repo overrides».
2. **Ссылка работы переписана сверх экранирования**: старая карточка показывала хардкод «efko.digital»; новый код выводит hostname из `d.url` и добавляет `rel="noopener noreferrer"` (timeline.js:62-64). Безвредно, но незапрошенное изменение. То же — эмит `data-slot` (timeline.js:68), который писался, но нигде не читался. → **Принято / частично исправлено:** `rel` — security-fix (старая разметка имела `target=_blank` без rel); hostname для efko.digital не изменился; `data-slot` **удалён**.

## (c) Implemented but looks wrong

1. **Регресс контраста в light-теме.** `.exp-label { color: #a1a1aa }` хардкодит тёмное значение; соседние правила используют токены, а `[data-theme="light"]` переопределяет `--text-secondary: #656d76` (style.css:1682). На `--page-bg: #f5f0eb` метка «опыт» даёт ~2.1:1 — конфликтует с *«Тема: дефолт dark, существующий переключатель light сохраняется»* (читаемость в обеих темах). → **Исправлено:** `color: var(--text-secondary)` (dark #a1a1aa — то же значение, light — #656d76).
2. **Дыра в reduced-motion.** Spec Implementation Decisions: *«все необязательные анимации уважают prefers-reduced-motion»*. Media query гасит `.experience, .exp-item`, но не `.exp-link { transition: opacity .3s }`. → **Исправлено:** `.exp-link` добавлен в reduced-motion блок.
