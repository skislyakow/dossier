## Найденное (по серьёзности)

### 1. [HIGH] Локального гейта нет — цепочки собираются руками и ломаются тихо
- **Симптом:** гейт собирался строкой `ruff && mypy && pytest -q | tail -3 && … && echo GATE_OK`. Код выхода конвейера берётся у `tail`, а не у `pytest`, поэтому при падающем тесте печаталось `GATE_OK` — ложнозелёный. Плюс CI-строка `node --check static/js/*.js` проверяет только **первый** файл (лишние аргументы node игнорирует), т.е. баг-хук в самом CI.
- **Действие:** `tools/gate.sh` — `set -euo pipefail`, ruff → mypy → pytest → makemigrations --check → `node --check` по каждому файлу; Dev workflow в AGENTS ссылается на него. CI переведён на тот же цикл. ✅

### 2. [MEDIUM] Дубли JS-хелперов поймало ревью, а не проверка
- **Симптом:** `esc()` и `prefersReducedMotion()` жили каждый в 2+ файлах (vanilla JS без общего модуля). Тест на единственность появился только после code-review и покрывал лишь portfolio/timeline.
- **Действие:** тест обобщён — общие хелперы (`function esc(`, `function prefersReducedMotion(`) определяет только `util.js`, проверка идёт по всем `static/js/*.js`. Механический паттерн → детерминированный чек, не правило ревью. ✅

### 3. [MEDIUM] Scope-изменения afterword'а не попадали в трекер
- **Симптом:** t23/t24 + og/uv + dedup t27/t28 сделаны по прямой просьбе, но зафиксированы только в переписке; Spec-ось code-review отметила это как «scope creep»/расхождение со спекой.
- **Действие:** при авторизации изменения объёма сразу дописывать тикет/спеку (или открывать новый) — трекер остаётся источником правды. Процессное; кода не требует.

### 4. [LOW] CI-поллинг выглядел как зависание
- **Симптом:** длинный inline-loop со `sleep` показался подвисанием — сессию перезапустили.
- **Действие:** `tools/ci-watch.sh <short-sha>` — токен из git credential store, ограниченное число попыток, видимый прогресс `[i/N]`, exit 0/1/2. ✅

### 5. [LOW] `smoke.sh` недочитывал python-чеки в итоге
- **Симптом:** «Итого: 11 ок» при ~19 фактических проверках — python-блок печатал PASS/FAIL, но не влиял на счётчики shell.
- **Действие:** python-блок считает свои pass/fail и отдаёт их суффиксом `# counts: P F`; shell суммирует. ✅
