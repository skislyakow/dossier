# 0001 — Таксономия принадлежит серверу

Date: 2026-10-11
Status: Accepted
Decision-makers: владелец сайта (решения приняты в ходе grilling, оба раунда — «да»)

## Context

Размеры тегов (кегль в секциях Skills и Projects) и резолв тега навыка (`filter_tag || name`) считались в двух местах:

- `views.py`: локальная `skill_size()` для `/api/skills/`.
- `portfolio.js`: дублирующая `tagSize()` для облака тегов проектов (`Project.tags` вниз по клиенту).

Правило «5+→xl / 3–4→lg / 1–2→md / 0→sm» и путь резолва жили в двух реализациях — их приходилось синхронизировать руками, логика облака тегов (частота по опубликованным проектам, сортировка) вообще не имела одного владельца. JS подсчитывал теги по карточкам `/api/projects/`, а секция Skills брала размеры из `/api/skills/` — два источника для одного понятия «сколько раз тег встречается в опубликованных проектах».

## Decision

Хозяин таксономии — один серверный модуль `main/taxonomy.py`:

- `skill_size(count)` — пороги: 5+→xl / 3–4→lg / 1–2→md / 0→sm.
- `resolve_tag(skill)` — `filter_tag || name`.
- `tag_counts()` — частоты тегов опубликованных проектов.
- `tag_cloud()` — облако `[{name, count, size}]`, сортировка по убыванию частоты, затем по имени.

Единый источник правды переиспользуется в `/api/skills/`, `/api/tags/` и `audit_content`. JS и HTML не считают размеры и не агрегируют теги — только рендерят.

`/api/skills/` возвращает `tag` — уже резолвнутый тег (одно поле вместо пары `name`/`filter_tag`); клик по навыку в шаблоне читает `data-tag`.

Облако тегов проектов приходит готовым с сервера через новое JSON-эндпоинт `/api/tags/` — JS лишь рендерит кнопки с классами размера.

## Consequences

- Пороги и правила резолва меняются в одном файле; `portfolio.js` больше не содержит копию бакетов.
- Поле `filter_tag` остается в модели (данные), но не в JSON-контрактах — клиент работает с `tag`.
- `/api/projects/` не дёргается ради таксономии — облако питается из `/api/tags/`.
- Навык, чей резолв-тег не встречается в опубликованных проектах, получает `size: "sm"` (порог 0) — старое поведение сохранено.
