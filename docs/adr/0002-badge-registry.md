# 0002 — Реестр бейджей — единый источник каталога и резолвера

Date: 2026-10-11
Status: Accepted
Decision-makers: владелец сайта (выбран следующий кандидат архитектурного ревью)

## Context

Один и тот же контракт источников бейджей («source-name») был закодирован в трёх местах:

- `widgets.py`: `GITHUB_BADGES`/`PYPI_BADGES` — каталог для пикера админки (13 записей: лейбл, иконка, source).
- `badge_utils.py`: `resolve_badge()` — elif-цепочка из 13 веток, выбирающая значение по `source`.
- `AGENTS.md`: таблица источников — перечисляла только 10 из 13.

Рассинхрон был **молчаливым**: источник, попавший в каталог, но потерявшийся в резолвере (или наоборот), давал бейджу `None` — бейдж исчезал без ошибки. Проект с `badges_config = [{"source": "miscataloged"}]` просто терял бейдж на сайте. Резолверы инлайнили логику форматирования (даты, размер, скачивания, версии Python) внутри сетевого вызова-обёртки — их нельзя было юнит-тестировать напрямую.

## Decision

Единый серверный реестр `BADGE_SOURCES` в `main/badge_utils.py` — отображение `source → {label, icon, group, resolve}`:

- `label`/`icon`/`group` — данные для каталога пикера (`group`: `github`/`pypi`);
- `resolve(ctx)` — чистый резолвер, принимающий `ctx = {repo, langs, pypi, stats}` и возвращающий строку или `None`.

От реестра питаются все три потребляющих места:

- `widgets.py`: `catalog()` собирает каталог из реестра, `BadgePickerWidget` не хранит своих копий списков.
- `resolve_badge()`: ищет запись по `source`, вызывает её `resolve(ctx)`.
- Тесты (`BadgeSourceRegistryTest`, `BadgePickerWidgetTest`): каждый источник резолвится на полном фикстуре-контексте, деградирует в `None` на пустом контексте (без падения), каталог виджета покрывает весь реестр.

Custom-бейдж (без `source`, со `value` или только с `label`) обрабатывается по-прежнему напрямую в `resolve_badge`.

## Consequences

- Добавление/изменение бейджа = одна запись в реестре; каталог и резолвер не могут разойтись.
- Резолверы стали чистыми и юнит-тестируемыми — логика форматирования проверяется без сети.
- Неизвестный `source` (данные, введённые мимо пикера, устаревшая конфигурация) по-прежнему деградирует в `None` — сайт не падает, но каталог пикера теперь гарантированно покрывает все резолвнутые источники.
- `AGENTS.md` объявляет реестр источником правды; таблица источников пополнена до 13 (было 10).
