# Dossier

Персональный сайт-визитка Python-разработчика: показывает проекты, опыт и навыки рекрутерам и заказчикам.

## Language

**Проект**:
Продакшн-работа с публичным репозиторием, показываемая на сайте самостоятельной карточкой.
_Avoid_: кейс, публикация

**Усиленная карточка**:
Формат показа проекта: таглайн, 3–4 конкретных буллета результата, динамические бейджи и ссылки.
_Avoid_: кейс, превью

**Signature-момент**:
Дизайн-элемент, задающий первое впечатление за первые секунды — oversized-типографика Hero с scroll-reveal.
_Avoid_: фишка, анимация-якорь

**Категория навыка**:
Зона экспертизы, по которой группируются навыки: Backend / Web / DevOps / Bots & Integrations / Tools.
_Avoid_: уровень, стек

**Тег проекта**:
Курируемая короткая метка стека проекта (Django, aiogram, Redis…), задаваемая в админке. В секции Projects теги показываются облаком `{ тег: N }`; тег без опубликованных проектов в облако не попадает, кегль растёт с частотой.
_Avoid_: категория, топик, фича

**Тег фильтра навыка**:
Поле `Skill.filter_tag` — тег проекта, по которому клик по навыку фильтрует список проектов. Для навыков, чьё имя не совпадает с тегом проекта (Telegram Bot API → Telegram, vk_api/VK API → VK), задаётся в админке; иначе резолвится по имени навыка (`filter_tag || name`).
_Avoid_: синоним, алиас категории

**Опыт**:
Хронология карьеры по датам — работы, проекты, текущий статус.
_Avoid_: таймлайн, timeline
