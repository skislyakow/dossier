# Dossier

Персональный сайт-визитка Python-разработчика: показывает проекты, опыт и навыки рекрутерам и заказчикам.

## Language

**Проект**:
Продакшн-работа с публичным репозиторием, показываемая на сайте самостоятельной карточкой.
_Avoid_: кейс, публикация

**Усиленная карточка**:
Формат показа проекта: таглайн, 3–4 конкретных буллета результата, динамические бейджи и ссылки.
_Avoid_: кейс, превью

**Signature-момент**:
Дизайн-элемент, задающий первое впечатление за первые секунды — oversized-типографика Hero с scroll-reveal.
_Avoid_: фишка, анимация-якорь

**Категория навыка**:
Зона экспертизы, по которой группируются навыки: Backend / Web / DevOps / Bots & Integrations / Tools.
_Avoid_: уровень, стек

**Опыт**:
Хронология карьеры по датам — работы, проекты, текущий статус.
_Avoid_: таймлайн, timeline
